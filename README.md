# 팀플 회의시간 맞추기

팀플 회의 시간을 매주 정할 때 쓰는 웹앱입니다. 수업처럼 매주 반복되는 시간을 한 번만 등록해 두면 새 주마다 자동으로 "불가"로 깔리고, 그 주에 바뀐 칸만 고친 뒤 팀원들과 겹치는 시간을 바로 볼 수 있습니다.

👉 **https://chanhomin.github.io/team-meets/**

설치, 회원가입, 로그인이 필요 없습니다. 휴대폰이나 PC 브라우저에서 주소만 열면 됩니다.
카카오톡에서 링크를 누르면 미리보기 창에서 동작이 안 될 수 있으니 "다른 브라우저로 열기"로 Chrome이나 Safari에서 여세요.

## 사용법

### 처음 한 번
1. **설정** 탭에서 이름을 입력합니다. 팀원 화면에 이 이름으로 표시됩니다.
   - 하루 시간 범위(기본 9:00~23:00)와 주말 포함 여부도 여기서 바꿀 수 있습니다.
2. **내 가능시간** 탭에서 **[고정 시간 편집]**을 누르고, 수업처럼 매주 반복되는 불가 시간을 칠한 뒤 **[완료]**를 누릅니다.

### 매주
3. **내 가능시간** 탭에서 이번 주 가능한 시간을 누르거나 드래그해서 칠합니다. 칠한 칸을 다시 누르면 지워집니다.
   - 회색 칸은 고정 불가 시간입니다. 휴강처럼 이번 주만 비는 경우 회색 칸을 누르면 **이번 주만** 가능으로 풀립니다. 다른 주와 고정 시간은 그대로입니다.
   - ◀ 이전 주 / 다음 주 ▶ 로 다른 주를 고를 수 있습니다.
4. **[내 코드 복사]**를 누르고 단톡방에 붙여넣습니다.

### 겹치는 시간 보기
5. 단톡방에 올라온 팀원들의 코드를 복사해 **팀 겹침 보기** 탭에 붙여넣고 **[추가]**를 누릅니다. 줄을 바꿔서 여러 개를 한 번에 붙여도 됩니다.
   - 내 시간은 자동으로 포함되므로 내 코드는 붙이지 않아도 됩니다.
6. 가능한 인원 수마다 칸 색이 다릅니다(1명 노랑, 2명 주황, 3명 초록 …). 몇 명인지는 위쪽 범례에서 확인하고, **파란 칸은 전원 가능**입니다. 칸을 누르거나 가리키면 가능/불가 명단이 나옵니다.

**내 가능시간** 화면의 칸 색:

| 칸 색 | 뜻 |
|---|---|
| 초록 | 가능 |
| 흰색 | 불가 |
| 회색 | 고정 불가 (수업 등) |
| 초록 + 빗금 테두리 | 이번 주만 푼 고정 칸 |

## 알아둘 점
- **데이터는 각자 기기의 브라우저에만 저장됩니다.** 서버가 없어서 휴대폰에서 칠한 내용은 PC에서 보이지 않고, 브라우저 데이터를 지우면 사라집니다.
- **시간을 바꾸면 코드를 다시 보내야 합니다.** 자동으로 반영되지 않습니다. 같은 이름의 코드를 다시 붙이면 덮어씁니다.
- **같은 주의 코드끼리만 합쳐집니다.** 다른 주의 코드를 붙이면 무시하고 이유를 알려줍니다.
- **팀원끼리 이름이 겹치지 않게** 하세요. 같은 이름은 같은 사람으로 보고 덮어씁니다.
- **고정 시간을 바꾸면 아직 입력하지 않은 주부터 적용됩니다.** 이미 칠한 주는 바뀌지 않습니다.
- 설정에서 시간 범위를 좁혀도 범위 밖에 칠한 칸은 지워지지 않고 보관됩니다. 공유 코드와 팀 겹침에는 지금 보이는 범위만 들어갑니다.

## 직접 실행하기
빌드 도구가 필요 없는 정적 웹페이지(HTML/CSS/JS)입니다. 저장소를 내려받아 `index.html`을 브라우저로 열면 바로 동작합니다.

```
git clone https://github.com/chanhomin/team-meets.git
open team-meets/index.html
```

Fork한 뒤 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 지정하면 내 GitHub Pages 주소로도 쓸 수 있습니다.
